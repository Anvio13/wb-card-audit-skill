# Аудит карточек Wildberries

## Результат

Проведи доказательный аудит одной или нескольких карточек Wildberries и покажи:

1. как карточка представлена сейчас;
2. по каким запросам и на каких позициях она находится;
3. с какими прямыми конкурентами реально сравнивает её покупатель;
4. где подтверждённые разрывы в цене, предложении, SEO и контенте;
5. что сохранить, исправить, проверить и не менять без теста;
6. как измерить эффект изменений.

Соблюдай порядок:

**карточка → запросы → выдача → прямые конкуренты → сравнение → отзывы → диагноз → рекомендации → эксперимент**.

Не формируй рекомендации до завершения конкурентного анализа.

## Обязательные ограничения

- Всегда фиксируй дату, регион, валюту, сортировку, состояние авторизации и способ получения данных.
- Не называй единичный снимок выдачи постоянной позицией.
- Не выдавай рекламную позицию за органическую; неизвестный тип помечай `тип размещения не подтверждён`.
- Не считай смежный товар прямым конкурентом.
- Не смешивай массовый дешёвый и премиальный сегменты без объяснения.
- Не используй отзывы как точное число продаж.
- Не объявляй конверсию низкой без данных кабинета продавца.
- Не придумывай характеристики и доказательства.
- Не переписывай работающее поисковое ядро без подтверждённой причины.
- Каждую рекомендацию связывай с конкретным фактом из выдачи, карточек, отзывов или кабинета.
- Не изменяй карточки в кабинете без отдельного разрешения пользователя.

## Контрольные шлюзы

### Шлюз 0 — входные данные

Продолжай, только когда:

- ссылки разделены и дубли удалены;
- артикулы определены;
- регион и дата зафиксированы;
- ограничения перечислены.

### Шлюз 1 — карточка

Для каждой карточки должна быть отдельная строка исходного состояния: название, бренд, категория, цена, рейтинг, отзывы, продавец, фото, видео, описание, характеристики, варианты, наличие и доставка, если доступны.

### Шлюз 2 — запросы

Определи минимум два небрендовых запроса, брендовый запрос при необходимости и один основной запрос с объяснением выбора.

### Шлюз 3 — выдача

Собери топ-20 по основному запросу, проверь карточку в топ-100 и сними минимум топ-10 по дополнительным запросам. Укажи регион, дату, сортировку и ограничения персонализации.

До прохождения шлюза 3 рекомендации запрещены.

### Шлюз 4 — конкуренты

Классифицируй кандидатов и выбери минимум пять прямых конкурентов. Смежные товары исключи из медиан.

## Выполнение

Прочитай [references/workflow.md](references/workflow.md) и выполни этапы 0–9 по порядку.

Для итогового ответа используй формы из [references/report-template.md](references/report-template.md).

## Остановка при нехватке данных

Если живую выдачу получить нельзя, не подменяй её поисковым кэшем и не заявляй, что полный аудит завершён. Напиши:

> Конкурентный анализ ограничен: точные позиции не подтверждены.

Если нет данных кабинета, напиши:

> Найдены факторы, которые могут снижать конверсию. Фактические показатели кабинета не предоставлены.

Если прямых конкурентов меньше пяти, расширь карту запросов, но не заполняй выборку нерелевантными товарами.

## Критерий завершения

Аудит завершён, только если пользователь видит:

- позицию своей карточки;
- минимум пять прямых конкурентов;
- сравнительную таблицу;
- подтверждённые сильные и слабые стороны;
- основания каждой рекомендации;
- готовые изменения, если они запрошены;
- элементы, которые нельзя менять без теста;
- план измерения результата.
