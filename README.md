# Audit WB Product Cards

Skill для доказательного аудита карточек Wildberries. Он не начинает с общих советов: сначала фиксирует карточку, строит карту запросов, снимает живую выдачу, выбирает прямых конкурентов и только после этого формирует рекомендации.

## Что получает пользователь

| Обычный промпт | Этот skill |
|---|---|
| Рассматривает карточку изолированно | Сравнивает её с текущей выдачей и прямыми конкурентами |
| Может дать универсальные советы | Привязывает каждый совет к данным |
| Смешивает прямых и смежных конкурентов | Классифицирует товары и считает медианы только по прямым конкурентам |
| Не проверяет реальные позиции | Снимает топ-20, ищет карточку до топ-100 и повторяет ключевой срез |
| Может разрушить работающее SEO | Выделяет элементы, которые нужно сохранить и не менять без теста |
| Часто игнорирует отзывы | Использует отзывы для поиска дефектов, ожиданий и причин покупки |
| Выдаёт список идей | Даёт приоритеты, риски, уверенность и план измерения |
| Может додумать свойства | Помечает неизвестные значения и требует подтверждения |

## Суперфичи

- **Антигаллюцинационные шлюзы.** Рекомендации заблокированы, пока не собраны запросы, выдача и минимум пять прямых конкурентов.
- **Живая позиция, а не SEO-теория.** В отчёте есть запрос, место, регион, дата, сортировка и ограничения персонализации.
- **Честная конкурентная выборка.** Дешёвые мини-товары, премиальные ориентиры и смежные решения не смешиваются в одну медиану.
- **Защита работающей карточки.** Skill отдельно показывает, что сохранить и что нельзя менять без теста.
- **Диагноз вместо свалки советов.** Проблемы разделяются на видимость, предложение, контентные риски и операции.
- **Голос покупателя.** Свежие отзывы превращаются в темы: причины покупки, дефекты, возражения и несоответствие ожиданий.
- **Готовый контент.** По запросу пользователь получает новое название, описание, характеристики и сценарий первых изображений.
- **Контролируемый эксперимент.** Результат проверяется через 14 и 21–28 дней без одновременной смены всех переменных.
- **Прозрачные ограничения.** Если данные недоступны, skill снижает уверенность, а не подменяет факты догадками.

## Пример запроса

```text
Используй $audit-wb-product-cards.
Проведи аудит карточки https://www.wildberries.ru/catalog/156678435/detail.aspx.
Покажи запросы и позиции, минимум пять прямых конкурентов, сравнительную таблицу,
сильные и слабые стороны, рекомендации по SEO, тексту, характеристикам и галерее.
Регион — Россия, Москва.
```

## Установка

Скопируйте папку `audit-wb-product-cards` в каталог skills вашего агента. Для Codex по умолчанию:

```bash
~/.codex/skills/audit-wb-product-cards/
```

После установки skill можно вызвать явно через `$audit-wb-product-cards`; описание также позволяет автоматически подобрать его для аудита конкретных карточек WB.

## Ограничения

Полный аудит требует доступа к актуальной витрине Wildberries. Регион, авторизация, реклама, персонализация, остатки и доставка могут менять выдачу. Без данных кабинета skill оценивает только риски для конверсии, а не фактическую конверсию.
